# \# PIE DIAFOOT — Estación Autónoma de Escaneo

# 

# \## Descripción del proyecto

# 

# PIE DIAFOOT es un proyecto académico de Sistemas Programables orientado al desarrollo de una estación autónoma de escaneo para apoyar el monitoreo preventivo del pie diabético.

# 

# La propuesta contempla la integración de hardware, sensores, procesamiento de información y una interfaz para la consulta de resultados.

# 

# \*\*Estado del proyecto:\*\* Estructura inicial del repositorio. El desarrollo y la documentación se completarán conforme avance el equipo.
